# batteries
Various modules for use with Lute

> [!NOTE]
> Projects using flipbook-batteries vendor its dependencies with `lute pkg install --vendor` (Lute `1.0.1-nightly.20261117` or newer) and define `lpm = "./.lpm"` in their `.config.luau`. [flipbook-labs/flipbook#694](https://github.com/flipbook-labs/flipbook/issues/694) tracks dropping this requirement.
